# Claude Code Workspace

Espaço de trabalho pessoal para explorar e testar o Claude Code.

## O que é isso?

Este repositório serve como ambiente de aprendizado e experimentação com o Claude Code — a CLI oficial da Anthropic para trabalhar com IA diretamente no terminal.

## Como usar

1. Instale o Claude Code: `npm install -g @anthropic-ai/claude-code`
2. Abra esta pasta no terminal
3. Execute: `claude`
